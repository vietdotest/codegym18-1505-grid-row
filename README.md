# Grid Row

Ba lưới 3 cột/3 hàng 100px, thể hiện đủ 1/3, 2/4 và span 2 theo yêu cầu.

## Chạy
Mở index.html trong trình duyệt. Các ví dụ có kích thước cố định được đặt trong khung cuộn ở màn hình nhỏ để giữ đúng giá trị thuộc tính.
